# NERVA_Ring_Charger
So this is the charger for the NERVA Ring, I suggest taking a look: https://github.com/NRG24/NERVA_Ring This portable charger is equipped with a 100mAh battery for charging the ring's 22mAh battery with a complex power path management/selection system.
